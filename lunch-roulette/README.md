# lunch-roulette 🍚

버튼 하나로 회사 근처 점심 메뉴를 랜덤 추천해주는 미니 기기.

- 버튼 누르기 → 룰렛이 돌아감
- 한 번 더 누르기 → 점점 느려지다가 멈춤 → **오늘은 여기!**
- 직전에 나온 곳은 바로 다시 안 나옴

## 준비물

| 부품 | 비고 |
| --- | --- |
| LilyGO TTGO **T-Display** (ESP32, 1.14" 화면) | 화면 + 버튼 내장 |
| (선택) 키캡 + 기계식 스위치 | 없으면 보드 내장 버튼으로 동작 |
| USB-C 케이블 | 데이터 전송 되는 것 |

## 키캡 버튼 연결 (선택)

스위치 다리 2개를 각각 이렇게 연결하면 끝 (저항 필요 없음):

```
스위치 다리 1 ── GPIO 21
스위치 다리 2 ── GND
```

키캡 없이도 보드의 **GPIO0 버튼**(USB 포트 옆 왼쪽 버튼)으로 똑같이 동작합니다.

## 식당 목록 바꾸기

[`src/menus.h`](src/menus.h) 파일만 수정하면 됩니다.

```cpp
{"식당 이름", "종류", 도보 몇 분},
```

한 줄씩 추가/삭제하고 다시 업로드하세요.

## 업로드 방법

1. [VS Code](https://code.visualstudio.com/) 설치
2. 확장 프로그램에서 **PlatformIO IDE** 설치
3. VS Code에서 이 `lunch-roulette` 폴더 열기
4. 보드를 USB로 연결
5. 하단 파란 바의 **→ (Upload)** 버튼 클릭

필요한 라이브러리(TFT_eSPI, 한글 폰트용 U8g2_for_TFT_eSPI)와 화면 설정은
`platformio.ini`에 들어 있어서 자동으로 설치/적용됩니다.

## 문제 해결

- **업로드가 안 됨**: 보드의 오른쪽 버튼(BOOT)을 누른 채로 업로드 시작
- **화면이 안 켜짐 / 이상한 색**: 보드가 T-Display(ST7789, 135x240)가 맞는지 확인
- **한글이 깨짐**: `src/menus.h` 파일이 UTF-8로 저장됐는지 확인
