# interior-tf

우리집 턴키 인테리어를 같이 준비하는 Claude TF 작업실. 명령창에 지시하면 총괄 PM이 팀원에게 일을 나눠주고, 팀원들이 서로 일을 넘겨가며 결과를 프로젝트 보드에 쌓는다.

- 라이브: https://claude.ai/artifact/Q7UgyYAoX6ucPwT3obKXx2 (claude.ai 아티팩트, 나만 볼 수 있음)

## 팀 구성 (평면도의 방 하나 = 팀원 한 명)

| 방 | 팀원 | 하는 일 |
| --- | --- | --- |
| 거실 | 총괄 PM | 지시를 읽고 1~3명에게 일을 나눔, 일정·우선순위 |
| 현관 | 리서치 | 업체·자재·레퍼런스 찾는 경로, 업체 고르는 기준, 상담 질문 |
| 안방 | 계약 | 표준계약서 조항, 대금 비율, 하자보수, 관리사무소 신고 |
| 주방 | 비용 | 공정별 견적 항목, 예산 배분, 견적 비교 |
| 작은방 | 비주얼 | 스타일 키워드, 컬러·마감재 방향, 디자인 브리프 |
| 서재 | 기록·연락 | 회의록, 업체 연락처·진행 상태, 할 일 |
| 발코니 | 보고서 | 요청할 때만 물어본 내용을 HTML 한 장(A4) 보고서로 작성 |

## 쓰는 법

- 그냥 지시 → 총괄 PM이 담당자를 정함
- `@비용 …`, `@계약 …`처럼 쓰면 그 팀원에게 바로 전달
- 팀원이 다른 팀원에게 일을 넘기면(handoff) 평면도에 연결선이 그려지고 로그에 남음 (지시 1번당 최대 2번)
- 보드 탭: 할 일 / 업체·연락처 / 예산·견적 / 회의록 / 결정사항 / 보고서. 직접 추가·체크·삭제 가능
- `@보고서 …`라고 하거나 지시에 "보고서로/한 장으로"를 넣으면 다른 팀원 작업이 끝난 뒤 보고서 팀원이 마지막에 HTML 한 장 보고서를 만든다. 보고서 탭에서 열고, HTML 파일로 저장 가능

## 구조

- `index.html` 한 파일. claude.ai 아티팩트 런타임 기능 사용
  - `sample`: 페이지 안에서 Claude 호출 (보는 사람의 Claude 사용량 사용)
  - `db`: 보드(`state/board`), 작업 로그(`log`), 보고서(`reports`) 저장
  - `downloads`: 보고서를 .html 파일로 저장
- 페이지 안 팀원은 웹 검색을 못 한다. 실제 업체 검색은 Claude Code 세션에서 "TF 보드 읽고 ○○ 찾아서 넣어줘"라고 하면 웹 검색 후 같은 DB에 써 넣을 수 있다.
- GitHub Pages 등 claude.ai 밖에서 열면 미리보기만 된다.
